# 🛡️ CyberShield3 - Modular Security Tool

**CyberShield3** adalah alat keamanan modular berbasis Bash Shell untuk analisis hash malware, pemantauan integritas berkas (FIM), dan karantina terisolasi di Linux (disesuaikan untuk Parrot OS / Kali Linux).

---

## 🚀 Panduan Instalasi & Penggunaan

### Prasyarat
- Sistem Operasi: **Linux** (Parrot OS, Kali Linux, Ubuntu, Debian)
- Package Manager: `git`, `bash`, `coreutils`

---

### 📥 1. Unduh (Clone) Repositori, beri izin eksekusi, dan menjalankan tools
Buka terminal Anda dan jalankan perintah berikut untuk mengunduh proyek:

```
git clone [https://github.com/arongifari/CyberShield.git](https://github.com/arongifari/CyberShield.git)
cd CyberShield

chmod +x cybershield.sh

./cybershield.sh
